# CyberSATC

Mateus Buogo destacou a importância de pensar em segurança no desenvolvimento das aplicações. Segue abaixo duas tecnologias que podem ser utilizadas para proteger sistemas de backend contra ataques cibernéticos:

### Sistemas de Detecção e Prevenção de Intrusões

- Introdução

Os Sistemas de Detecção e Prevenção de Intrusões monitoram as redes e sistemas para proteger os contra ataques cibernéticos. Esses sistemas observam o tráfego de rede e identificam padrões suspeitos que indicam atividades maliciosas.

- Funcionamento

Quando um sistema detecta uma ameaça, ele pode tomar medidas como bloquear o acesso ao invasor ou notificar um responsável sobre uma tentativa de ataque. A instalação desses sistemas reforça a segurança e serve como proteção contra invasões e vulnerabilidades.

- Benefícios

Esses sistemas podem ser instalados em diferentes partes da rede, oferecendo proteção para diversos aspectos da infraestrutura tecnológica. Ao identificar ameaças precocemente e responder rapidamente, os IDS/IPS ajudam a reduzir riscos e manter os dados seguros.

### Firewalls

- Introdução

Firewalls são mecanismos de segurança que protegem as redes contra ameaças cibernéticas. Eles funcionam como barreiras controladas, examinando pacotes de dados que tentam acessar ou sair da rede.

- Funcionamento

Usando regras pré-definidas, os firewalls analisam elementos do pacote de dados para decidir se o tráfego é permitido ou bloqueado. Isso garante que apenas conexões autorizadas tenham acesso à rede e protejam contra ataques maliciosos.

- Configuração

Os firewalls podem ser configurados de maneiras diferentes, desde opções simples até sistemas complexos com várias camadas de segurança. Existem diferentes tipos de firewalls, como os baseados em hardware ou software, que se integram fisicamente ou virtualmente à infraestrutura da rede.

- Posição

A posição do firewall pode variar, sendo possível acessá-lo na borda da rede (firewall de gateway), entre servidores internos (firewall perimetral) ou mesmo em cada dispositivo individual (firewall host). Essa flexibilidade permite adaptar a proteção às necessidades específicas de cada ambiente.
